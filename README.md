# Image Grid｜图片宫格工具

**图片拼接与宫格拆分工具，提供网页版与 Windows EXE。**

**[打开网页版 →](https://shifengblues.github.io/ImageGrid/)** · **[下载 Windows 版 →](https://github.com/shifengblues/ImageGrid/releases/latest)**

把多张图片排成一张整齐的宫格，或者把一张宫格图拆成多张独立图片。拖入图片、调整布局、预览效果，再导出保存。

适合整理照片、制作图片合集、对比设计方案、排列参考素材，也可以用于分镜展示和 AI 宫格图片拆分。图像处理在自己的电脑上完成，无需登录、无需上传图片。Windows 版可以直接离线使用。

## 网页版

Mac、Windows 用户都可以通过浏览器打开 [Image Grid Web](https://shifengblues.github.io/ImageGrid/)。支持本地文件和文件夹导入、宫格合成与拆分、自动填满、原像素、统一尺寸、排序与删除、HSV 选色、PNG/JPG 导出和浅深色主题。

网页由 GitHub Pages 静态托管，图片读取、计算和编码在访问者自己的设备中完成。没有图片上传接口和统计脚本；发布页面还通过内容安全策略禁止网络数据连接。加载网页及程序资源需要网络，暂未提供离线重新打开网站的功能。

支持文件夹写入的浏览器可以把拆分结果保存到用户选定的文件夹；其他浏览器下载 ZIP 后解压即可。文件夹读取和写入都需要用户主动选择授权。

网页版 1.0.1 和 Windows 1.0.9 已取消软件自定的固定内存与边长配额，实际能力受设备、浏览器及图像格式限制；不承诺无限大小，也不会自动降低画质。已在测试机器上验证 25 张 3840×2160 图片拼成 5×5，并输出 19212×10812 PNG/JPG。详见 [大图与高清预览验证](docs/LARGE-GRID-1.0.9.md)。

网页版放大时按可见区域加载高清预览，4K 图片在 100% 查看时加载至原图尺寸并对齐屏幕像素，高清缓存按需回收。常见 8 位 PNG 在原像素 PNG 导出与拆分时保留解码像素；其他输入的解码、颜色和 JPG 编码可能因浏览器而异。高位深会转换为 8 位，不保留专业色彩管理和原始元数据。旧版验证记录见 [网页版验证记录](docs/WEB-VALIDATION.md)。

网页版源码位于 `web/`。开发需要 Node.js 24 或更新的兼容版本：

```sh
cd web
npm ci
npm test
npm run dev
```

`npm run build` 生成静态网站。推送 `web/` 的修改到 `main` 后，GitHub Actions 自动测试、构建并发布至 GitHub Pages。

## 下载与运行

支持 **Windows 10 / Windows 11，64 位系统**。

在右侧 **Releases** 下载 EXE，双击即可运行，无需安装，也不需要另外安装 .NET 或 Python。更新时关闭旧版，再打开新版 EXE。

## 宫格合成

- 提供 2×2、3×3、4×4、5×5 快捷布局；行数、列数均支持 1–10，最多 100 个格子，实际可处理尺寸受内存限制。
- 支持 16:9、9:16、1:1、4:3、3:2 和自定义单格比例。
- 自定义内部间距、间距颜色和画布背景色。
- 拖动画布图片或底部缩略图调整顺序；可单张替换，点击缩略图右上角「×」删除。
- 导出 PNG 或质量 100 的 JPG。

图片数量超过宫格容量时，会提示增加行列或删除多余图片，避免导出时漏掉内容。

### 三种图片处理方式

| 模式 | 显示效果 | 适合的情况 |
| --- | --- | --- |
| 自动填满，默认 | 自动计算统一单格，小图等比放大并居中填满，比例不同时裁切边缘 | 希望每格铺满、排列整齐 |
| 原像素 | 按原尺寸居中放置，不缩放、不裁切，小图周围可能留白 | 保留解码后的原始像素 |
| 统一尺寸 | 自定义单格像素宽高，选择 Fit 或 Fill | 控制最终输出尺寸 |

**Fit** 保持比例完整显示，允许留白；**Fill** 保持比例填满格子，居中裁切。两者都不会把图片拉变形。放大小图无法增加源图中不存在的细节。

## 宫格拆分

导入一张宫格图，设置行列，批量导出独立 PNG 图片。

- 支持均匀切分，也可以拖动绿色虚线调整分割位置。
- 支持输入原图像素坐标，精确设置分界线。
- 使用「每边内缩」裁去每个区域边缘的分隔框或留白。
- 可以随时恢复均匀等分。

按从左到右、从上到下的顺序导出并自动编号，预览辅助线和序号不会写入图片。遇到同名输出时，会创建独立子文件夹，保留原有文件。

## 支持格式

| 操作 | 格式 |
| --- | --- |
| 导入 | PNG、JPG / JPEG、WebP、BMP |
| 合成导出 | PNG、JPG |
| 拆分导出 | PNG |

PNG 使用无损编码并支持透明通道。JPG 使用质量 100 编码，仍属于有损格式；JPG 不支持透明通道，透明区域按画布背景色合成。

## 快速上手

**合成图片：** 进入「宫格合成」→ 导入或拖入多张图片 → 设置行列、比例、模式和间距 → 调整顺序 → 选择格式并导出。

**拆分图片：** 进入「宫格拆分」→ 导入一张宫格图 → 设置行列并调整绿色分割线 → 按需设置内缩 → 点击「导出全部图片」。

多张拖入时会追加到列表；单张拖到已有格子上会替换该位置。批量导入顺序以 Windows 提供给软件的顺序为准，不保证还原资源管理器中 Ctrl 逐张点击的先后顺序。

## 预览与外观

- 滚轮缩放，右键或中键拖动画布，「适应窗口」恢复整体视图。
- 「100%」按像素比例查看局部；导出始终重新读取源图，不会使用底部小缩略图生成成品。
- 绿色主题，支持浅色、深色、跟随系统；在左下角切换。
- 颜色支持色板、HEX、RGB 输入。
- 处理时显示进度并提供取消按钮；导出完成后可直接打开输出文件夹。

## 常见问题

**原像素模式下，小图为什么留白？**

这个模式不会放大图片。希望每格铺满时，切换到「自动填满」。

**内部间距调整后，为什么变化不明显？**

间距按最终导出图片的像素计算。整图很大、预览缩得很小时，几像素的变化可能看不清，可以增大间距或放大画布查看。

**放大预览后，为什么变模糊？**

预览为了控制内存占用设有清晰度上限，最长边最多 4096px。超过上限放大会模糊，不代表导出使用了同样的低分辨率图片。

**会删除原图吗？**

删除列表项目、清空列表都不会删除磁盘原文件；导出也会阻止覆盖当前导入的源图片。

## 当前边界

动画图片仅处理首帧；关闭软件后不保存工作区。超大图片受内存和处理上限约束，超限会提示，不会悄悄降低导出分辨率。不提供专业色彩管理，不承诺保留高位深、广色域或完整图片元数据。详见 [兼容边界与限制](docs/KNOWN-LIMITATIONS.md)。

## 源码与构建

使用 C#、WPF、.NET 10 和 SkiaSharp。安装 .NET 10 SDK 后，在项目根目录运行：

```powershell
./scripts/build.ps1
./scripts/publish.ps1
```

首次构建需要联网获取依赖，发布后的程序可以离线使用。`src` 为源码，`tests` 为回归测试，`scripts` 为构建与发布脚本。EXE 采用 Windows x64 自包含单文件发布。
