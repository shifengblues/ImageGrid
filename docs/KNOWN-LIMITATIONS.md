# 兼容边界与限制

- 默认自动填满会等比重采样，比例不一致时居中裁切；放大不能恢复源图中不存在的细节。需要不缩放、不裁切时选择原像素模式。

- 输入统一解码为每通道 8 位 BGRA；应用 EXIF 方向。普通 8 位 PNG / BMP 的解码像素可精确保留；高位深、广色域、ICC、CMYK 输入不承诺原始数值或专业色彩管理保真，元数据不会复制到输出。建议重要色彩素材先在专业工具转换为标准 sRGB 8 位 PNG。
- JPEG / WebP 的「无损输出」指解码后像素保存为 PNG，不代表恢复有损压缩之前的信息。动画图片仅处理首帧，没有动画导出能力。
- 原像素模式和拆分保留解码后的透明度，包含透明像素 RGB。缩略图会缩小并预乘透明度，只供查看，不能用来核验单像素差异；导出从源图重新解码。
- 单边尺寸最多 65535px；工作像素缓冲安全限额仍为 768MB 或 GC 可用进程内存预算的三分之一（取较低者）。1.0.3 按处理阶段估算峰值，解码无需方向转换时不再复制整图，拆分共享原图像素提取区域；PNG/JPG 编码共享只读像素，避免额外整图拷贝。仍不支持无限大小流式拼图，超限不降低分辨率而是显示估算值与当前限额。
- 合成可选普通 JPEG 质量 100，仍为有损压缩，不能保证与 Photoshop 的编码结果、文件体积一致。保持像素宽高不代表逐像素无损；透明区域按用户设置的画布背景色合成。拆分固定 PNG，不引入第二次 JPEG 损失。
- 原生图像解码和 PNG 编码阶段不能立即打断；取消会在当前阶段结束后生效，随后删除临时文件。拆分失败/取消会尝试删除本次已成功输出的文件，已有同名文件不覆盖。若外部权限变化导致清理失败，可能需手工删除本次残留文件。
- 导入任务取消时，已成功导入的图片会保留；导入失败逐个提示，不影响正常图片。
- 底部列表缓存最长边 480px 的缩略图。画布按需异步加载最长边最多 4096px 的预览，额外像素缓存上限 64MB；达到缓存预算时部分格子暂用小缩略图，再次缩放或适应窗口可重试清晰加载。超过预览分辨率后继续放大会模糊，导出始终使用源图。PNG / BMP 编解码器可能需要先解码完整源图再缩小，超出安全限额的源图会拒绝处理。
- 仅记住本次运行中的图片、参数、导出目录；退出不保存工作区。两页行列布局独立，切分线在本次运行的页面切换间保留。源图若在外部改变尺寸，需要重新导入后再导出；恢复可读性后可点击适应窗口重试清晰预览。尺寸未变而内容改变时，导出使用再次解码时的源文件数据，不进行文件内容版本校验。
- 原生依赖首次自动解包到用户临时目录，需要可写空间。EXE 未做商业数字签名，也没有安装器或自动更新。
- 适配 Windows 10 / 11 x64，声明 PerMonitorV2；当前机器验证不能替代不同系统版本、多显示器和全部 DPI 配置的实机测试。
