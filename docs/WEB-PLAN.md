# 网页版开发与验收

目标：保留 Windows EXE，增加无需上传图片的静态网页版。延续绿色主题、Logo、浅深色模式，优先桌面 Chrome / Edge / Firefox / Safari。

1. 图像核心：移植布局、缩放与分割几何；浏览器 Worker 处理导出，PNG 保留常见 8 位像素。验证实际 PNG/JPG 像素、透明度、尺寸、ZIP 与超限提示。
2. 完整界面：合成、拆分、导入文件/文件夹、排序/替换/删除、分割线、比例间距、颜色、主题。验证浏览器真实交互、响应式排版、失败恢复和无图片上传。
3. 发布：构建静态资源，更新开源说明，用 GitHub Pages 发布并读取公开网址验证。Windows 1.0.8 发布文件不变。

本地处理指用户图片不发送到服务器；页面和程序资源由静态托管分发。浏览器需要用户主动选择文件，文件夹写入能力不足时使用 ZIP 下载。
